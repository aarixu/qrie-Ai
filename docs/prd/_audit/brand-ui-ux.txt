AREA: Brand, UI and UX (apps/classroom, packages/stage, packages/board-layout, brand assets)

== VERIFIED SUMMARY (post adversarial check) ==
There is a real design system. One token file (apps/classroom/src/theme.css:21-130) carries Material-3 role names as RGB triplets, and tailwind.config.js:16-67 maps every semantic colour onto them — though spacing, radius, font family and font size in that same file (:95-130) are literal values, and the thirteen stage-* colours (:81-93) are raw hex. Type is self-hosted with Devanagari companions (fonts.ts:27-38); 75 Lucide glyphs sit behind one tested component (Icon.tsx:91-167); four shared non-content states (States.tsx:27-213) reach nine screens. I recomputed the contrast: the main text pairs run 16-17:1, and the failures reproduce too — text-outline on cream is 3.99:1, text-outline-variant on white 1.56:1.

What is missing is brand. Two unrelated marks ship — an atom (Logo.tsx:19-47) and a penguin (CartoonAvatar.tsx:28-38) — and I sampled the PNGs directly: every launcher icon, adaptive layer and native splash is #4648d4 indigo on #f7f9fb, while the app is cream (#fdf6ea, index.html:6). targetSdkVersion is 36 with exactly one env(safe-area-inset) in the whole app (ClassRoom.tsx:1204). Notes and Bookmarks are complete screens with no create path: addNote is called only from tests, and toggleBookmark's one product caller removes (Bookmarks.tsx:111). Help.tsx:99 tells children every class was taught live to real students; there are none. Locked achievements draw a bullet because 'lock' is the only referenced icon name with no glyph — and icon.test.tsx:42's lazy regex cannot see the second branch of a ternary. The board layout engine, packages/board-layout, is the area's best work and went unexamined.

Every sticky header draws under the status-bar clock and the five-tab bottom nav draws under the gesture pill.   - Brand-correct app icon, adaptive icon, native splash and manifest colours.

      The classes are narrated in Hinglish and the product bundles six Devanagari font files for that, but 100% of buttons, headings, empty states and error copy are English.
