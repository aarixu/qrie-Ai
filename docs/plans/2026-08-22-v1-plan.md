# AI Tutor — V1 Plan

**Date:** 2026-08-22
**UI language:** Established-edtech (Duolingo-style) — locked. Light surfaces, Nunito
700–900, chunky press-down buttons, 2px/4px bordered cards, saturated tokens.
All UI and content in English.

## UI architecture

### Screen map

```
Onboarding (first run: pick class 6-12)
    │
Home ──────────────┬──────────────┐
 │ chapters         │              │
 ▼                  ▼              ▼
Chapter (topics)  Profile       Settings (inside Profile for v1)
 ▼
Lesson Player ──► Lesson Complete (recap + next-lesson CTA)
```

### Decisions

- **React Router** (`/`, `/onboarding`, `/chapter/:id`, `/lesson/:id`, `/complete/:id`,
  `/profile`) — deep-linkable lessons.
- **Responsive:** mobile-first single centered column (max ~600px lists, ~900px canvas),
  the established learning-app web pattern. Same codebase becomes a **PWA** (phase E)
  and later a Play Store app via Capacitor — never two apps.
- **Component structure:** `ui/` primitives (Button, ProgressBar, TileIcon, icons) on
  `theme.ts` tokens · `screens/` compose only · `stores/` (settings, progress,
  doubt-log) are localStorage-backed behind tiny adapters · logic stays in packages.
- **Topics ↔ lessons** join on `topicRef` (`content/index.json` ↔ syllabus paths).
  A topic without a lesson shows as "coming soon" — content grows with zero code.

## Phases

| Phase | Scope | Deliverable |
|---|---|---|
| **A — App shell** | Router, onboarding, Home (syllabus browse), Chapter, Lesson Complete, Profile, stores (settings/progress/doubt-log), resume, responsive pass | A navigable app, not a lone player |
| **B — Real doubt agent** | Gemini behind `AgentAdapter`; doubt logging per beat | The differentiator, live (needs `GOOGLE_API_KEY`) |
| **C — Content scale** | Factory-generate all Life Processes topics + one Class 9 chapter, human review | A full chapter — the app reads as a course |
| **D — Retention** | Streak surfacing, per-beat doubt analytics view | Data spine visible |
| **E — Ship** | PWA manifest + SW, deploy to a public URL | Installable, shareable |
| F (post-v1) | Voice doubt (Gemini Live), cloud TTS, generated images/3D, Capacitor | — |

Doubt logging (every ✋ with its beat id) starts in Phase A — the data spine
collects from day one even before the analytics view exists.
